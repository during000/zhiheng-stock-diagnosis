# 第三题测试说明

自动化：tests/screen.test.mjs覆盖真实入选排除、修改单条件新增候选、PE缺失、已失败且有缺失、接口失败/过期/冲突、矛盾及严格边界、负净资产/负利润/不足窗口、非法字段/重复ID、模型造阈值/引用/窗口。tests/screen-api.test.mjs覆盖确认门槛、服务端执行、矛盾拒绝、异常结果、D1保存与刷新恢复、跨浏览器隔离、客户端伪造结果不被保存、交易/过长/坏JSON边界。

UI验收：真实模型解析模糊语言，黄色示例确认，执行得到真实候选；逐条件打开凭据，比较股票，修改条件后提示旧结果不可保存，重算归属差异；保存后刷新载入；矛盾示例阻止执行；单PE条件显示缺失；返回诊断携带研究问题。实际验证记录见screen-validation.json，测试输出screen-test-results.txt。

数据验证：三家公司行情结束日一致且至少65个收盘价，60日窗口使用61价格/60收益；未复权最新收盘与估值时点匹配，财报期末股本近似边界明确；财务数据来自同半年。半年报未经审计，不补造行业/一致预期/全市场资料。

持久化：D1新增screen_saves及工作区/时间联合索引；每份快照独立不可变，服务器重算后保存，单语句限定最多30份，查询仅按HttpOnly随机cookie工作区。数据库失败503提示可导出/重试。用户切换策略需明确载入，不静默替换历史数据版本。

合规：不输出交易指令、目标价、确定性涨跌或收益承诺；阈值只是一组研究假设。条件敏感性不是回测，不使用未来收益证明策略有效。没有实测生产数据供应商中断或完整渗透测试；模式规则与AI提取可能误判，用户检查仍必要。

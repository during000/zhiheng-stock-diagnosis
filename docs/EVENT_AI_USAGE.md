# 第二题 AI 使用与验证记录

开发协作：Codex帮助核验题意、设计状态机、实现界面/API/测试，所有真实数字来自公司原公告，而非生成模型。原文件链接、页码、SHA与采集时点保存于data/events.json。R01董事会发生9月20日、披露9月21日；R04生效6月26日、披露6月28日；R05发生8月29日、披露8月30日，刻意避免混用时间。

产品AI：服务端通过OpenRouter调用google/gemini-2.5-flash，提取company/eventType/anchor/kind/quote/summary。模型必须逐字引用输入，原方案日期与股票代码必须在原文出现；摘要中的数字必须在输入出现；输出结构、类别、长度、建议词校验失败则拒绝归档。输入视为不可信数据，系统提示要求忽略其中指令。UI允许修改提案；无锚点不能提交；任何用户材料核验前weight=0、verified=false，分类为事实不代表事实已证实。

确定性代码负责事件ID、按披露时间排序、去重、字段合并、同日矛盾、否认/更正目标、时效、版本与通知。语言模型不决定已核验来源、财务影响数字或投资建议。

失败：缺密钥503；接口超时/错误/JSON或引用不合规502；显示明确错误、不落库、不冒充生成。已入库研究可继续查看。网络材料不执行任意URL抓取，避免来源冒充和服务器任意网络访问。

验证记录：见自动化event tests与event-api tests，覆盖造引用/造锚点/造数字/交易建议拒绝。实时模型与UI验证结果另存event-validation.json（若尚未生成，请勿宣称完成）。

# 第二题演示脚本（90–120秒）

1. 0–12秒：进入事件情报，说明这是五节点真实历史公告回放，非实时完整资讯；最初只归档方案。
2. 12–30秒：导入首次回购与四月进展，看到同一事件更新、版本与通知。点原始证据，显示发生、披露、采集、入库、更新时间，PDF页码与SHA。
3. 30–45秒：导入价格调整与完成公告，累计金额/股数更新；“拟注销”依然待核验。查看版本比较，再导入重复材料，展示没有新通知。
4. 45–65秒：AI提取默认评论，检查原方案日期和“观点”分类，确认归档，展示未核验不改变确认事实。改变原方案日期可另建事件。
5. 65–90秒：进入隔离演练区，依次传闻→否认→更正→研究观点；查看通知；导入同期冲突材料，显示双方而非武断选择；推进时钟使观点过期。
6. 90–105秒：展示通知前后值与版本追溯；回到真实案例，沿标的关系返回诊断，说明第三题意图选股仍待实现。

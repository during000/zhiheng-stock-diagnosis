## 自动化

`node --test tests/engine.test.mjs tests/api.test.mjs`（API测试需要服务已启动）。

| 范围 | 覆盖 |
|---|---|
| 核心数字 | 半年报收入/利润/现金流同比与公告核对；毛利率；TTM利润和PE，不将半年利润简单翻倍 |
| 诊断主链路 | 问题路由、用户维度覆盖、证据元数据完整、真实模型返回live及有效引用 |
| 数据异常 | 行情缺失、接口失败、字段冲突隔离、过期阻断；保留已核验财务证据 |
| 极端计算 | 零分母、负利润、空/非法行情返回不可计算；最大回撤历史峰值算法 |
| AI错误 | 幻觉数字、无效ID、将推断写成事实的结构拒绝；无依据渠道占比变化拒绝 |
| 合规边界 | 买卖、目标价、收益承诺问题不进入模型决策链；保留可研究证据 |
| 接口 | 健康状态、非法维度、超长输入、JSON错误处理路径 |

异常演练是显式测试模拟，不冒充真实公司坏消息。其作用是验证应用如何停止结论和表达未知；扶摇适配层新增业务错误、超时、缺失、冲突、重复日期与时点异常测试；iFinD未接入。

## 浏览器实际验证

- 点击“生成诊断”：真实返回实时AI解读，维度变为经营质量与财务趋势，分析引用可点击。
- 点击现金流数字：抽屉显示两期人民币元输入、公式、合并口径、报告期间、披露/抓取时间和PDF第5页入口。
- 财务期次：展示3年年度与2个半年期，表格结构、来源按钮正常。
- 估值敏感性：键盘改变假设价格，PE联动，明确“用户假设价格，非实际行情”；恢复快照价格可用。
- 行情区间：切换20日样本，日期范围、区间收益、回撤及年化波动同步变化。
- 失败场景：选择“模拟接口失败”，PE变为不可计算，行情路径显示暂停当前计算。
- 390px手机宽度：document内容宽度与视口宽度均为390，无页面级横向溢出；实际截图检查。
- WebMCP：`open_evidence`已注册；有效F04打开同一抽屉并返回摘要；无效ID抛错，不改变证据。

# 第三题：自然语言智能选股与策略解释器

|要求|实现|
|---|---|
|自然语言澄清|实时模型提取意图片段与字段、操作符；无明确阿拉伯数字的模糊阈值返回null。产品示例值另行标示，用户需检查确认；支持手动修改指标、数值、窗口与增删条件。|
|结构化可执行条件|字段与运算符白名单，AND，10–64交易日窗口；可见条件与服务端执行同一DSL。模型不能编造金融字段或数字。|
|冲突识别与修改|同指标上下限与严格等号边界检测，矛盾阻止执行；未支持行业/OR/指标明确提示，用户需改写或明确移除。|
|真实候选与排除|三家白酒真实财报、公开日线；逐股逐条件显示实际值、阈值、通过/失败/未知。任何已知失败即可排除，但其余缺失不隐藏。|
|条件变化影响|同一数据逐条放宽的反事实计算；用户应用到草稿后再确认执行；显示与上次执行的归属变化。不是收益预测。|
|数据口径、时点、缺失|收入归母利润同比、PB、PE-TTM、波动、回撤、现金流；来源PDF页码、原字段、公式、抓取及披露、哈希；PE缺全年利润留空。|
|继续研究|多股比较；D1保存策略和完整结果快照、刷新载入；JSON导出；茅台进入诊断/事件并回到条件。其他样本完整诊断未实现，不伪跳转茅台。|
|Web/源码/README|/screen；同一网站三模块相连。现有网站受限访问，正式评审需所有者开放。|
|AI记录/测试|SCREEN_AI_USAGE、SCREEN_TESTING及screen-validation.json。视频可选，此次不重复录制第三题视频。|

## 用户与产品选择

面向希望检查自己模糊选股想法的个人研究者；聚焦可解释条件编译，不做黑盒荐股。使用三家公司人工样本，以同一期间财报与同一行情截止日减少不可比因素；范围显著展示，不冒充全市场筛选。样本选择有偏差，结果不能泛化到行业整体。

默认示例收入同比≥0、归母同比≥0、PB≤8、60日波动≤35。PB与波动阈值只是可修改例子，不是金融工具给出的“合理值”。默认五粮液入选，茅台因利润同比下降排除；五粮液经营现金流仍为负，需继续核验，筛选不等于全面经营改善。

没有扶摇/iFinD授权，未接入。官方公开定期报告与腾讯替代行情源均标明；原始PDF不复制到仓库。没有全A覆盖、实时服务承诺、回测、策略收益、后台监控、投资排名或交易执行。保存/比较满足提交要求中的研究延续选项，未把静态快照包装成回测。

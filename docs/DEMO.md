# 约120秒演示脚本（非视频）

0—15秒：打开产品，说明选股为贵州茅台。展示财务截至2026半年、披露时间、行情快照日期及扶摇接入、iFinD未接入的边界。

15—40秒：输入“收入、利润与现金流的变化一致吗？”，生成实时AI诊断。查看系统选择的经营质量与财务趋势，可手动修改。指出收入增长、利润下降以及合并现金流含财务子公司的矛盾。

40—60秒：点击经营现金流数字，查看原始两期数值、人民币元、同比公式、2026半年报第5页与披露日期。打开原始PDF；强调现金流增长不自动等于酒类回款改善。

60—80秒：切换财务期次查看年度和半年比较；切换估值与行情，调整假设价格，说明PE会变化但不等于目标价；切换20/40/65日行情样本。

80—95秒：查看两家同行的相同半年口径及独立报告来源；查看渠道改革与合同负债的待验证影响。

95—110秒：异常演练切换行情缺失或接口失败，显示未知，停止估值计算。再输入买卖建议问题，展示边界提示。

110—120秒：恢复正常资料，导出JSON研究记录；说明该产品提供证据、解释与验证路径，不作买卖建议。

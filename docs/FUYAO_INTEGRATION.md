# 扶摇接入与验证（2026-10-08）

已实际调用行情快照、历史日线、利润表、现金流量表、估值快照，均返回业务code=0。三家公司各65根历史收盘价截至2026-09-30；2026H1收入、归母利润、经营现金流及2025H1收入/归母利润与人工核验公告逐项一致。

## 产品中的实际作用

- 正常筛选执行和保存优先读取扶摇前复权、未复权历史日线；后者用于PB/PE，前者用于波动和回撤。
- 扶摇利润表/现金流字段与公告比对一致后，进入筛选的原始字段及确定性计算。净资产、股本及未接入的附注仍取一手公告。
- 正常诊断生成使用扶摇历史行情计算估值和行情证据，并保留公告、期次与页码。初始页面是明确标示的公开核验快照；生成后显示扶摇已核验。
- 三模块顶栏共用“扶摇数据核验”，展示最新成交价、PE-TTM/PB-MRQ、行情与估值各自时点、请求ID，以及财务字段的核验凭据。事件回链可继续核验标的；不推断事件导致涨跌。
- 最新估值的供应商口径不替换历史PB/PE，避免将今天的快照混入2026-09-30固定窗口。历史财务报告期保持2026H1；Q2按半年累计理解。

## 鉴权、缓存和异常

密钥仅本机忽略的.env和Sites服务端secret；不会发送到浏览器。请求不接受任意URL，只访问固定官方域名及三个样本。每个服务端实例缓存15分钟，并合并同时发生的取数请求；不承诺全局共享缓存或定时采集。

未配置密钥时明确使用公开历史快照。配置后权限不足、HTTP/业务错误、空字段、财务冲突、重复日期、窗口不足或结束时点不符均报错并阻止正常执行，不静默回退。缓存过期后失败，不返回过期缓存冒充已成功刷新。模拟异常继续单独隔离。

官方文档将缺密钥列为2001，但实际未鉴权探测返回2003/Missing X-api-key；适配器同时处理两者，不能只以HTTP 200判断成功。
